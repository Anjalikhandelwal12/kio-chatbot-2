# Kio Chatbot 2.0

A chatbot built with Angular and TypeScript that searches Wikipedia and shows a summary, image and related topics for any query.

**Live demo:** https://kio-chatbot-2.vercel.app

## Features
- Search any topic and get a Wikipedia summary with thumbnail
- Related topic chips you can click to explore further
- Link to the full Wikipedia article

## Tech Stack
Angular, TypeScript, Wikipedia REST API, Vercel
